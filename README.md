# FIGBOT

Private source snapshot, 2026-10-01.

- `figbot/`: original project source and documentation.
- `figbot-lerobot-lab/`: separate LeRobot and virtual leader experiments.

Physical calibration, mechanical limits and hardware reliability remain unverified. Wrist overheating was reported. The replacement motor ID change remains pending because no valid motor replies were received. Do not treat software tests as physical validation.

Environments, model weights, camera recordings, runtime logs, generated CAD exports, published packages and temporary files are excluded. SOURCE_MANIFEST.json records SHA256 hashes of included originals. The source working folders remain at their existing locations; this checkout is a publication snapshot and does not automatically synchronize future edits.

# Manufacturing package boundary

These instructions are process-planning inputs for the V0 prototype. CAD source,
released drawings and BOM take precedence for geometry, quantity and material. Any
conflict is a stop-work condition and must be resolved by engineering.

No dimension, tolerance, print recipe, silicone cure or joint strength in this
folder has been physically verified. Status: `UNVERIFIED — MANUFACTURING REVIEW
AND PHYSICAL VALIDATION REQUIRED`.

Before fabrication, a responsible human must release a revisioned traveler that
identifies the drawing revision, material certificate/lot where applicable,
inspection instruments and disposition of deviations. Never scale an STL, STEP or
DXF to compensate for an unreviewed process error.

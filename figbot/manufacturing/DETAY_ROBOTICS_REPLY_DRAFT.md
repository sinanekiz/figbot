The robot is intended to use a camera to locate objects on the ground, collect them with a robotic arm and place them in the onboard basket. The attached files represent a preliminary V1 demonstration and feasibility design, not a frozen production design.

Each handled object weighs no more than 100 g. We need a lightweight, economical and fast arm rather than a high-payload industrial robot. The 100 g value is object mass only, and arm/gripper mass, dynamic loads and appropriate engineering margins must still be included in sizing.

Our requested system objective is 50-100 successfully collected objects per minute within a 5 m2 test area. This ambitious objective is unverified and is being shared for feasibility assessment; it is not a performance claim for the current CAD. Sequential collection would require 0.6-1.2 seconds per object. Please state the achievable V1 rate and recommend an alternative architecture or realistic initial-demo target if necessary. The complete timed test should include camera detection, gripping, basket deposit, retries and any required base repositioning.

Our team will develop the software, computer vision and control algorithms. Any supplied controller, motor driver, compute or sensor hardware must remain programmable after delivery and include documented interfaces, protocol/API/SDK information and firmware-loading access. A vendor-locked control system is not acceptable.

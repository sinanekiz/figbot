# Post-assembly inspection record

Record configuration ID, selected gripper variant, camera/mount revision, funnel
revision, firmware/software commit and every deviation. Photograph front/rear/left/
right/top/isometric views and joint/cable details with the arm de-energized.

Measure and record base stability, manually observable joint play, hard-stop margin,
cable clearance, gripper opening, funnel clearance and calibration check-point error
using approved methods. Acceptance numbers are drawn from released requirements;
otherwise mark `TBD` and do not issue a pass.

After the first low-energy cycles, reinspect fastener witness marks, printed-part
cracks, tube/shaft movement, bearing temperature/noise, coupling slip, cable scuffing
and stand movement. Any change stops testing pending disposition.
